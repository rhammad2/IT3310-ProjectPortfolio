## Task Dependencies

- Create Patient Intake Forms → Test the New System (Finish-to-Start)
- Train Clinic Staff → Launch at All Six Clinics (Finish-to-Start)
- Plan Appointment Scheduling → Build Appointment Scheduling (Finish-to-Start)

### Dependency Logic

If creating the patient intake forms takes two extra weeks, testing the system may also be delayed. This could delay staff training and the system launch. If there is extra time in the schedule, the team could use it to avoid delaying the launch. If there is no extra time, the team may need to change the schedule.

## Critical Path Analysis

Path A → B → D takes 9 days, and path A → C → D takes 11 days. The critical path is A → C → D because it takes the longest. The project takes 11 working days. If an activity on the critical path is delayed by two days, the project will finish two days late. Activity B can be delayed by up to two days without delaying the project because it has two days of extra time.
